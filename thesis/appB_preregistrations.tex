\chapter{Predictions Registered Before Their Data}\label{app:prereg}

Where a run tests a prediction, the prediction was committed to the repository before the data
existed, as a commit of its own. The table lists every such registration, including one whose experiment has not yet been run: the commit that holds
it, what it said, and what happened. Commits are those of the public repository history; each
registration is an ancestor of the commit that holds its data, which a reader can check with
\texttt{git log}.
